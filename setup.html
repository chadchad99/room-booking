잠금 파일 만들기

공용 비밀번호를 처음 정하거나 바꿀 때, 접속 열쇠를 새로 만들었을 때 쓰는 페이지입니다. 여기에 적는 내용은 이 브라우저 안에서만 쓰이고, 깃허브(api.github.com) 말고는 어디로도 보내지 않습니다.

접속 열쇠 만드는 법
  1. 깃허브에 로그인한 뒤 새 열쇠 만들기 화면을 엽니다. (Settings → Developer settings → Personal access tokens → Fine-grained tokens)
  2. Token name에 알아볼 이름(예: room-booking)을 적고, Expiration은 No expiration 또는 원하는 기간을 고릅니다.
  3. Repository access에서 Only select repositories를 고르고 자료 저장소 하나만 선택합니다.
  4. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  5. Generate token을 누르고, 나온 글자를 복사해 위 칸에 붙여 넣습니다. (이 글자는 그 화면에서 한 번만 보입니다)

전화번호·기관 이름처럼 짐작하기 쉬운 것은 피해 주세요. 직원 모두 이 비밀번호 하나로 들어옵니다.

잠금 파일이 만들어졌습니다

  1. 아래 글자를 복사합니다.
  2. 예약 페이지 저장소의 lock.json 파일을 열어, 안의 내용을 모두 지우고 붙여 넣은 뒤 Commit changes를 누릅니다.
  3. 1~2분 뒤 예약 페이지에서 새 비밀번호로 들어갑니다. 비밀번호는 직원들에게 따로 알려 주세요. (이 페이지는 비밀번호를 저장하지 않습니다)
